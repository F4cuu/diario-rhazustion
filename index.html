    Conectar con GitHub

    Para guardar, la página necesita permiso para escribir en el repositorio del diario. Se hace una sola vez en cada navegador, y el permiso queda guardado solo acá.

    1. Abrí github.com/settings/personal-access-tokens/new (con tu cuenta de GitHub).
    2. Token name: «Diario de Rhazustión». Expiration: la que quieras (hasta 1 año).
    3. Repository access: «Only select repositories» y elegí .
    4. Permissions → Repository permissions → Contents: «Read and write».
